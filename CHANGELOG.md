# dbt_claude v0.1.0

## Initial Release
This is the initial release of the Claude dbt package. It transforms data from the Fivetran Claude connector into four analytics-ready models covering API cost and usage, Claude Code activity, and enterprise user cost, usage, and engagement: `claude__platform_cost_usage_report`, `claude__enterprise_cost_usage_report`, `claude__code_report`, and `claude__user_summary`.
